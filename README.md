# MOOC Missions — Java

> Programming exercises completed as part of the University of Helsinki's MOOC Java programming course.

![Language](https://img.shields.io/badge/Language-Java-red) ![Type](https://img.shields.io/badge/Type-MOOC%20Assignments-orange) ![Course](https://img.shields.io/badge/Course-MOOC.fi%20Java-blue)

## About

Solutions to exercises from the **mooc.fi** (University of Helsinki) Java programming course — one of the most comprehensive free Java courses available. The course covers programming fundamentals through to object-oriented design using Java.

## Topics Covered

**Part 1–4 (Fundamentals)**
- Variables and printing
- Conditional statements and loops
- Methods and parameters
- Lists and arrays

**Part 5–7 (Object-Oriented Programming)**
- Classes and objects
- Class inheritance
- Interfaces and abstract classes

**Part 8–14 (Advanced)**
- Hash maps and sets
- Recursion
- File handling and exceptions
- Algorithms and data processing

## Getting Started

### Prerequisites

- Java JDK 11 or later
- An IDE such as IntelliJ IDEA or VS Code with Java extension

### Running an Exercise

```bash
javac ExerciseName.java
java ExerciseName
```

## Context

Completed alongside a game programming curriculum to broaden language experience beyond C++ and C#. The MOOC.fi Java course is a well-regarded free resource used by thousands of students worldwide.
